# AI 운명 플랫폼: Idea Elaboration

## Original Idea

> 사주팔자 같은거, 또는 점성술 같은거 서비스 하는 걸 아이디어 구체화 해봐. astro-seek.com 같은 사이트 참고.

## Executive Summary

사주팔자(동양 명리학)와 서양 점성술(Natal Chart)을 AI가 통합 해석해주는 한국어 기반 운세 플랫폼. 기존 서비스들이 "사주 OR 점성술"로 분리되어 있는 반면, 이 플랫폼은 두 체계를 교차 분석하여 더 풍부한 인사이트를 제공한다. Astro-Seek의 정밀한 천문 계산 + 점신/포스텔러의 한국형 사주 UX + AI 개인화 해석을 결합한 형태.

## Problem Analysis

### Primary Problem

- **무엇이 아픈가?** MZ세대는 커리어 전환, 연애, 재테크 등 중요한 의사결정에서 불확실성을 느끼고, 사주/점성술로 심리적 안정감과 방향성을 얻고자 함
- **얼마나 자주?** 주 1-3회 (일일 운세 확인 + 주요 결정 시 심층 상담)
- **해결 안 하면?** 심리적 불안감 지속, 유료 점집 방문 비용 (1회 5-20만원), 신뢰할 수 없는 무료 콘텐츠에 의존

### Current Alternatives

| 대안 | 설명 | 약점 |
|------|------|------|
| **점신** | 1,900만 유저, 전문 상담사 연결 | 사주 전문, 점성술 미지원. 상담 1회 2-5만원으로 비쌈 |
| **포스텔러** | 860만 유저, 사주+타로+점성술 | 콘텐츠가 일방향적, AI 해석 깊이 부족 |
| **헬로우봇** | 500만 유저, AI 챗봇 방식 | 사주 중심, 점성술 약함. 유료 전환 과도 |
| **Co-Star** | 3,000만 글로벌 유저, AI+NASA 데이터 | 영어 전용, 사주팔자 미지원, 한국 문화 맥락 부재 |
| **Astro-Seek** | 정밀한 점성술 계산, 풍부한 데이터 | 한국어 미지원, 사주 미지원, UX가 전문가 중심 |
| **사주GPT/운세박사** | ChatGPT 기반 사주 해석 | 매번 프롬프트 입력 필요, 지속적 관계 없음, 데이터 축적 안 됨 |
| **워크인:** 점집/역술원 방문 | 개인 맞춤 상담 | 1회 5-20만원, 접근성 낮음, 기록 안 남음 |

### Problem Severity Signal

- **검색 수요:** "사주팔자 무료", "오늘의 운세", "별자리 운세" 등 월 수백만 검색
- **지출 의향:** 한국 점술 시장 1.4조원 규모 (10-39세 1인당 평균 80,300원 소비)
- **커뮤니티 활동:** 사주/점성술 관련 네이버 카페, 에브리타임, Threads에서 활발한 논의
- **투자 유치:** 점신(테크랩스) 연매출 830억원, 포스텔러 42억원 투자 유치

## Target Customers

### Primary Persona

- **Who:** 25-34세 한국 여성 직장인, 커리어 전환기 또는 연애/결혼 고민 중
- **Size:** 한국 25-34세 여성 인구 약 350만명, 이 중 운세 관심층 약 60% = 210만명
- **Pain frequency:** 주 2-3회 (일일 운세 + 주요 이벤트 전 심층 분석)
- **Current spend:** 연간 평균 8만원 (무료 앱 + 가끔 유료 상담)
- **Where they gather:** 인스타그램, Threads, 에브리타임, 네이버 카페, 카카오톡 오픈채팅

### Secondary Persona

- **Who:** 25-39세 남성, 재테크/투자 타이밍에 운세 참고하는 층
- **Why secondary:** 시장 크기는 크지만 진입 빈도가 낮고 (월 1-2회), 유료 전환율이 상대적으로 낮음

### Anti-Persona (Who this is NOT for)

- **전문 역술가/점성술사:** 이미 전문 도구(포스텔러 프로 만세력 등)를 사용. 이들은 타겟이 아님
- **점술 회의론자:** 서비스 특성상 재미/관심이 선행되어야 함
- **10대 청소년:** 의사결정 맥락이 다르고 결제력 부족

## Product Concept

### One-Line Pitch

**AI 운명 플랫폼**은 **커리어/연애 고민이 많은 MZ세대**에게 **사주팔자와 서양 점성술을 AI가 통합 해석**하여, 중요한 의사결정에 맞춤형 인사이트를 제공합니다.

### Core Value Proposition

- **Before:** 사주 따로, 점성술 따로 봐야 하고, 무료 콘텐츠는 뻔하고, 심층 상담은 비쌈
- **After:** 생년월일시 한 번 입력으로 사주+점성술 통합 분석, AI가 내 상황에 맞춰 해석, 매일 새로운 인사이트
- **Magic moment:** "내 사주의 식신(食神)과 점성술의 금성(Venus) 위치가 모두 창작/표현력을 가리키네 - 지금이 콘텐츠 부업 시작할 타이밍이다" 같은 교차 인사이트를 받는 순간

### Core Features (Must-Have for MVP)

1. **통합 운명 프로필 생성** - 생년월일시+출생지 입력 → 사주팔자(년주/월주/일주/시주) + 서양 Natal Chart(태양/달/상승궁 등) 동시 계산 → 시각적으로 통합 대시보드 제공 → *양 체계를 동시에 보여주는 유일한 한국어 서비스*

2. **AI 통합 해석 엔진** - 사주 오행 분석 + 점성술 행성 배치를 교차 분석하여 자연어 해석 생성. 카테고리별 해석 (성격, 커리어, 연애, 재물, 건강) → *GPT 기반이지만 명리학+점성술 전문 프롬프트 엔지니어링으로 차별화*

3. **오늘의 운세 (Daily Insight)** - 매일 아침 푸시알림으로 오늘의 통합 운세 제공. 사주의 대운/세운/월운 흐름 + 당일 행성 트랜짓 반영 → *매일 재방문 유도하는 핵심 리텐션 기능*

4. **궁합 분석** - 두 사람의 사주 궁합 + 점성술 시너스트리(Synastry) 통합 분석 → *연애/결혼 맥락에서 바이럴 가능성 높은 기능*

5. **질문 기반 AI 상담** - "이직해야 할까요?", "이 사람과 결혼해도 될까요?" 같은 구체적 질문에 사주+점성술 근거로 AI가 답변 → *기존 앱 대비 인터랙티브한 차별점*

### Nice-to-Have Features (Post-MVP)

1. **전문가 연결** - AI 해석이 부족할 때 실제 역술가/점성술사 라이브 상담 연결 (점신 모델)
2. **타로 카드 통합** - AI 기반 타로 리딩 + 사주/점성술 교차 해석
3. **운세 저널/캘린더** - 매일의 운세를 기록하고 실제 결과와 비교하는 트래킹 기능
4. **친구/커플 그룹** - 친구끼리 궁합 보고, 오늘의 운세 공유하는 소셜 기능
5. **기업용 팀 궁합** - 팀원 간 업무 궁합, 프로젝트 시작 길일 추천 (B2B)

### Explicitly Out of Scope

1. **전문 역술가용 만세력 도구** - 포스텔러 프로가 이미 장악. 일반 사용자 타겟 유지
2. **글로벌 다국어 지원** - MVP는 한국어만. 한국 문화 맥락에 최적화 우선
3. **실시간 상담 마켓플레이스** - 점신이 이미 830억 매출로 장악. 초기엔 AI 중심

## Business Model

### Revenue Model

- **Type:** Freemium + 구독 + 단건 결제

| Tier | 가격 | 포함 기능 |
|------|------|-----------|
| **무료** | ₩0 | 기본 프로필(사주+차트), 일일 운세 1회, 기본 성격 해석 |
| **베이직** | ₩4,900/월 | 심층 AI 해석 무제한, 카테고리별 운세 (커리어/연애/재물), 월간/연간 운세 |
| **프리미엄** | ₩9,900/월 | 베이직 전체 + AI 질문 상담 무제한, 궁합 분석 무제한, 트랜짓 알림, 운세 저널 |
| **단건 결제** | ₩2,900-9,900/건 | 궁합 분석 1회, 심층 커리어 리포트, 연간 운세 리포트 등 |

### 가격 설정 근거

- 점신 상담 1회 2-5만원 대비 월 4,900-9,900원은 매우 합리적
- 넷플릭스(₩5,500~) / 스포티파이(₩10,900) 수준의 가격대
- 단건 결제로 비구독자도 수익 기여

### Unit Economics (Estimated)

- **Target MRR (12 months):** ₩30,000,000 (약 $23,000)
- **Customers needed at target:** 유료 구독 4,000명 (평균 ₩7,500/월)
- **Estimated CAC:** ₩3,000-5,000 (SNS 바이럴 + 인스타 광고)
- **Estimated LTV:** ₩90,000 (평균 12개월 유지 × ₩7,500)
- **LTV:CAC Ratio:** 18:1 ~ 30:1

### Revenue Milestones

- **Month 1-3:** ₩1-3M MRR (유료 200-400명) - 얼리어답터 검증
- **Month 4-6:** ₩5-10M MRR (유료 700-1,300명) - 구전/바이럴 성장
- **Month 7-12:** ₩20-30M MRR (유료 2,700-4,000명) - 안정적 성장

## MVP Definition

### MVP Goal

"사주+점성술 통합 AI 해석에 대한 사용자 수요가 있는가"를 검증하기 위해, 런칭 3개월 내 MAU 10,000명 / 유료 전환 200명 달성.

### MVP Feature Set

| Feature | Priority | Complexity | MVP 포함? |
|---------|----------|------------|-----------|
| 통합 프로필 (사주+Natal Chart) | Must | Medium | Yes |
| AI 통합 해석 (성격/커리어/연애/재물) | Must | Medium | Yes |
| 오늘의 운세 (Daily Push) | Must | Low | Yes |
| 궁합 분석 (사주+시너스트리) | Should | Medium | Yes |
| AI 질문 상담 | Should | Medium | Yes (제한적) |
| 타로 통합 | Could | Medium | No - Post-MVP |
| 전문가 연결 | Could | High | No - Post-MVP |
| 운세 저널/캘린더 | Could | Low | No - Post-MVP |
| 소셜/공유 기능 | Could | Medium | No - Post-MVP |

### Tech Stack Suggestion

- **Frontend:** Next.js 14+ (App Router) + TailwindCSS → SSR로 SEO 유리, 모바일 웹 우선
- **Backend:** Node.js + Express 또는 Next.js API Routes → 빠른 개발
- **Database:** PostgreSQL (Supabase) → 유저 프로필, 운세 히스토리 저장
- **AI:** OpenAI GPT-4 API → 사주+점성술 통합 해석 생성
- **사주 계산:** 만세력 알고리즘 직접 구현 (천간지지 계산 로직) 또는 오픈소스 활용
- **점성술 계산:** Swiss Ephemeris (오픈소스 천문력 라이브러리) 또는 Astro.js
- **Hosting:** Vercel (프론트) + Supabase (DB/Auth) → 초기 비용 최소화
- **Push 알림:** Firebase Cloud Messaging (FCM) 또는 웹 Push API
- **Key 3rd-party:** OpenAI API, Supabase Auth, Vercel Analytics

### MVP Success Criteria

- [ ] 런칭 3개월 내 가입자 10,000명
- [ ] 유료 전환 200명 (2% conversion)
- [ ] 일일 운세 확인율: DAU/MAU > 30%
- [ ] AI 해석 만족도 4.0/5.0 이상 (인앱 피드백)
- [ ] 궁합 분석 1인당 평균 2회 이상 사용 (바이럴 지표)
- [ ] 월 재방문율 60% 이상

## Go-to-Market Strategy

2. **카카오톡 공유** - 궁합 분석 결과를 카카오톡으로 공유 → 바이럴 루프 형성. "너랑 나 궁합 한번 봐봐" → Expected reach: 30,000+
3. **네이버 블로그/카페 SEO** - "2026 무료 사주", "별자리 궁합" 등 SEO 콘텐츠 → 검색 유입 → Expected reach: 20,000+
4. **에브리타임/대학 커뮤니티** - 대학생 타겟 궁합 이벤트, 사주 테마 콘텐츠 → Expected reach: 10,000+

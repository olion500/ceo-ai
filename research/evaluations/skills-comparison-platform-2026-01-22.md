# Business Idea Evaluation: Claude Code Skills Comparison Platform

## Executive Summary

**One-line pitch:** Claude Code Skills를 객관적 벤치마크와 주관적 Arena 투표로 비교할 수 있는 플랫폼

**Target market:** Claude Code 사용자 (개발자, AI 엔지니어, 팀 리드)

**Business model:** Freemium + Pay-per-test + Enterprise

**Unique angle:** Benchmark + Arena 하이브리드 - 객관적 성능 지표와 주관적 사용자 평가를 결합한 유일한 플랫폼

## Problem Statement

**What problem are you solving?**
Claude Code의 skills, agents, hooks 등 다양한 구성요소들 중 어떤 것이 더 효과적인지 비교하기 어려움

**Who experiences this problem?**
- Primary audience: Claude Code 사용자 (개발자, AI 엔지니어)
- Secondary audience: AI 코딩 도구에 관심있는 개발자, 기업 의사결정자
- Market segment: Developer tools / AI productivity

**How are they solving it today?**
- 현재 해결책 1: 개인적으로 여러 개 테스트해보고 비교
- 현재 해결책 2: Reddit, Twitter, Discord 커뮤니티에서 의견 수집
- Workarounds: 유명한 것만 따라 사용하거나 직접 만듦

**Why are current solutions inadequate?**
- Pain point 1: 체계적인 비교 데이터가 없음
- Pain point 2: 개인 리뷰는 주관적이고 재현 불가능
- Pain point 3: 시간이 많이 소요됨 (각각 테스트해야 함)

## Detailed Evaluation

### 1. Problem Intensity: 5/10

**Evidence:**
- Claude Code Skills 사용자는 아직 초기 단계 (2025년 10월 출시)
- SkillsMP에 71,000+ skills 등록되어 있어 선택 과부하 문제 존재
- 커뮤니티 포럼에서 "어떤 skill이 좋은지" 질문이 종종 올라옴
- 하지만 "반드시 해결해야 하는" 수준은 아님 - nice-to-have에 가까움

**Reasoning:** 문제는 존재하지만, 대부분 개발자는 그냥 유명한 것을 쓰거나 직접 만듦. "급한 고통"보다는 "있으면 좋은" 수준.

### 2. Market Size: 6/10

**Evidence:**
- Claude Code 사용자 수: 정확한 수치 미공개, 하지만 급성장 중
- AI 코딩 도구 시장: 82%의 기업이 GitHub Copilot 사용
- Skills marketplace 생태계 성장: 여러 마켓플레이스 등장
- 추정 TAM: AI 개발자 도구 관심자 수백만 명
- 추정 SAM: Claude Code 적극 사용자 10만~50만 명

**Reasoning:** 시장은 성장 중이지만, "Skills 비교"에 특화된 니즈는 전체 사용자의 일부. 연간 성장률 고려하면 미래 잠재력 있음.

### 3. Competition Level: 4/10

**Evidence:**
- 이미 존재하는 경쟁자들:
  - [SkillsMP](https://skillsmp.com/) - 71,000+ skills, 카테고리/인기도 필터링
  - [ClaudeCode.io Comparison](https://claudecode.io/comparison) - 도구간 비교
  - [LMArena](https://lmarena.ai/) - LLM 모델 Arena 스타일 비교
  - [JetBrains DPAI Arena](https://blog.jetbrains.com/blog/2025/10/28/introducing-developer-productivity-ai-arena-an-open-platform-for-ai-coding-agents-benchmarks/) - AI 코딩 에이전트 벤치마크
- GitHub에 여러 "awesome-claude-skills" 큐레이션 리포지토리 존재

**Reasoning:** 경쟁이 이미 상당함. 특히 SkillsMP가 71K+ skills로 마켓플레이스 점유. JetBrains는 벤치마크 플랫폼 출시. 차별화가 핵심.

### 4. Monetization Clarity: 6.5/10

**Evidence:**
- 제안된 수익 모델이 명확함 (아래 상세 분석 참조)
- 유료 전환 동기가 명확 ("내 유즈케이스로 테스트")
- B2B 확장 경로 존재
- API 비용 구조상 마진 확보 가능 (50-70%)

**Reasoning:** 초기 평가(5/10)에서 수익 모델 구체화 후 상향 조정. Freemium + Pay-per-test 조합이 개발자 타겟에 적합.

### 5. Differentiation: 6/10

**Evidence:**
- 제안된 차별화 포인트:
  - **Benchmark + Arena 하이브리드**: 객관적 성능 + 주관적 사용자 투표 조합
  - 기존 플랫폼은 둘 중 하나에만 집중
  - LMArena 모델을 Skills에 적용한 사례 없음
- Chatbot Arena 비판: "vibes-based evaluation" 한계 인정됨
- JetBrains DPAI Arena는 "패치 생성"에만 집중, skills 비교 아님

**Reasoning:** Benchmark + Arena 조합은 새로운 접근. 하지만 실행이 어렵고, 커뮤니티 구축이 필수.

### 6. Time to Market: 6/10

**Evidence:**
- MVP 범위:
  - Skill 메타데이터 수집/표시: 2-3주
  - 기본 벤치마크 (로딩 시간, 토큰 사용량): 1-2주
  - Arena 스타일 투표 시스템: 2-3주
  - 기본 UI/UX: 2-3주
- 예상 총 MVP 시간: 2-3개월

**Reasoning:** 기술적으로 복잡하지 않지만, 데이터 수집과 커뮤니티 참여가 핵심. 3개월 내 MVP 가능하나, 의미있는 데이터 축적에 시간 필요.

### 7. Solo/Small Team Fit: 6/10

**Evidence:**
- 가능한 부분:
  - 웹사이트 개발: 혼자 가능
  - 기본 벤치마크 자동화: 혼자 가능
  - 투표 시스템: 혼자 가능
- 어려운 부분:
  - 커뮤니티 구축/관리: 시간 소모
  - 지속적인 skill 테스트/업데이트: 운영 부담
  - 콘텐츠 마케팅/홍보: 리소스 필요

**Reasoning:** 기술적으로 솔로 가능하나, 성공적인 Arena는 커뮤니티 참여가 필수. 커뮤니티 빌딩에 상당한 시간 투자 필요.

### 8. Skills Match: 7/10

**Evidence:**
- 필요 스킬 vs 보유 스킬:
  - ✅ Claude Code Skills 깊은 이해 (본 프로젝트 경험)
  - ✅ 웹 개발 능력
  - ✅ 벤치마크 설계 경험 가능
  - ⚠️ 커뮤니티 빌딩 경험: 불확실
  - ⚠️ 마케팅/그로스 경험: 불확실

**Reasoning:** 기술적 스킬은 강점이나, 커뮤니티 중심 플랫폼 성공에 필요한 소프트 스킬은 검증 필요.

### Pricing Structure

| Tier | Price | Features |
|------|-------|----------|
| **Free** | $0 | Skills 등록/브라우징, 샘플 5개/skill, Arena 투표 |
| **Pay-per-test** | $2-5/회 | 내 유즈케이스 1개로 1개 skill 테스트, 상세 리포트 |
| **Pro** | $19-29/월 | 무제한 테스트, 동시 비교, 팀 공유 |
| **Enterprise** | 협의 | 사내 비공개 테스트, API, 커스텀 벤치마크 |

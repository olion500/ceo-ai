# Business Idea Evaluation: Tech Transition Learning Tool (기술 전환 도우미)

## Executive Summary

**One-line pitch:** 기존 기술 스택을 알고 있는 개발자가 새로운 기술로 빠르게 전환할 수 있도록 맞춤형 학습을 제공하는 AI 기반 도구

**Target market:**
- 기술 전환이 필요한 중급-고급 개발자
- Python → TypeScript, Express → Next.js, Git → jj 등

**Business model:**
- Freemium: 기본 전환 가이드 무료, 심화 학습 + AI 맞춤화 유료
- 월 $15-30 구독 또는 언어페어당 $50-100 일회성 구매

**Unique angle:**
- "Learn X in Y minutes" 스타일이지만 AI로 개인화
- 기존 지식 기반 맥락 매핑 (A에서 알던 것 → B에서 어떻게 하는지)

## Detailed Evaluation

### 1. Problem Intensity: 7/10

**Evidence:**
- 개발자들이 새로운 기술 학습에 평균 주 5시간 이상 투자 ([McKinsey](https://www.mckinsey.com/))
- "Python for JavaScript developers", "TypeScript for Python developers" 검색량 상당
- LinkedIn Learning, Udemy에 전환 과정 존재 → 수요 검증됨
- Reddit/HN에서 "coming from X" 질문 빈번

**Reasoning:**
문제는 실재하고 개발자들이 적극적으로 해결책을 찾지만, "career blocker" 수준은 아님. 대부분 공식 문서 + 프로젝트로 해결. 편의성 개선 수준.

**Confidence Level:** High
**Key Assumptions:**
- 개발자들이 시간 절약을 위해 비용 지불 의향 있음
- AI 개인화가 실제로 학습 효율을 높임

### 2. Market Size: 7/10

**Evidence:**

### 5. Differentiation: 5/10

**Evidence:**
- 현재 시장: 일반적인 "X for Y developers" 콘텐츠
- AI 코딩 도구: Cursor, Copilot은 학습보다 생산성 초점
- 기존 학습 플랫폼의 개인화 수준 낮음

**Potential Differentiation:**
1. **AI 맥락 매핑**: "Python에서 list comprehension → TypeScript에서는?"
2. **실시간 코드 변환**: 기존 코드를 새 언어로 변환하며 학습
3. **개인 코드베이스 분석**: "당신이 자주 쓰는 패턴의 새 언어 버전"

**Reasoning:**
아이디어 자체는 좋으나, 다른 플랫폼들도 AI 추가 가능. 장기적 moat 불명확.

**Confidence Level:** Medium
**Key Assumptions:**
- AI 개인화 품질로 차별화 유지 가능
- 경쟁사들의 AI 도입까지 시간 벌 수 있음

- AI로 콘텐츠 생성 가속화 가능

**Timeline Estimate:**

- 3개월: 베타 테스트, 추가 페어

**Reasoning:**
기술적으로 복잡하지 않으나, 콘텐츠 품질 확보가 관건. AI로 초안 생성 후 검수 필요.

**Confidence Level:** Medium
**Key Assumptions:**
- 콘텐츠 품질 기준을 적절히 설정
- LLM API 비용이 예산 내

## Recommendation

**Overall Assessment:** ITERATE (개선 후 진행 권장)

**Reasoning:**

이 아이디어는 **실제 수요가 있는 좋은 문제**를 다루고 있습니다. 개발자들이 기술 전환 시 겪는 어려움은 실재하며, "Python for JS developers" 같은 검색이 많다는 것이 증거입니다.

그러나 **경쟁 환경이 가장 큰 도전**입니다:
- Learn X in Y Minutes (무료, 78개 언어)
- FreeCodeCamp (무료, 고품질)
- Exercism (무료, 멘토링)

이들을 이기려면 **AI 개인화의 가치가 명확해야** 합니다. 단순히 "AI가 있어서 좋아요"가 아니라, **측정 가능한 시간 절약**을 보여줘야 합니다.

**현재 상태로 GO하기에는:**
- 차별화 포인트가 "AI 있음" 수준으로 약함
- 무료 대안 대비 가치 제안 불명확
- 장기적 moat 불분명

**ITERATE 후 GO하려면:**
1. 더 구체적인 포지셔닝 필요
2. 실제 사용자 인터뷰로 pain point 검증
3. 최소 기능으로 유료 전환 테스트

## Conditions for GO

- [ ] 5-10명의 잠재 고객 인터뷰 완료
- [ ] 무료 대안 대비 명확한 가치 제안 수립
- [ ] 1개 언어 페어로 빠른 프로토타입 + 피드백
- [ ] 유료 전환 의향 확인 (프리런치 사인업)

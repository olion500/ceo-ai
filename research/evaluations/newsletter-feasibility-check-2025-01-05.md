**주 10-20시간 투자 가능** ✅ 충분

3. **워크샵 형태**: 1회성 라이브 워크샵으로 시작

### 권장 전략: 하이브리드 접근

```
┌─────────────────────────────────────────────────────┐
│  PRIMARY (80% 시간)                                  │
│  ┌─────────────────────────────────────────────────┐│
│  │  "AI 코딩 마스터" 뉴스레터                        ││
│  │  = Claude Code 가이드 + Vibe Coding 통합         ││
│  │                                                  ││

│  │  - Claude Code, Cursor, MCP 튜토리얼            ││
│  │  - Vibe Coding 워크플로우                        ││
│  │  - 예상 시간: 주 8-12시간                        ││
│  └─────────────────────────────────────────────────┘│
│                                                     │
│  SECONDARY (20% 시간)                               │
│  ┌─────────────────────────────────────────────────┐│
│  │  Simon Willison 스타일 데일리 링크                ││
│  │  - 인디해커 + AI 뉴스 큐레이션                    ││
│  │  - 매일 35분 발행                                ││
│  │  - 예상 시간: 주 3-4시간                         ││
│  └─────────────────────────────────────────────────┘│

│  = 총 주 11-16시간 (목표 10-20시간 내)              │
└─────────────────────────────────────────────────────┘
```

### 왜 이 조합인가?

| 이유 | 설명 |
|------|------|
| **시너지** | Primary가 깊이, Secondary가 빈도 커버 |
| **리스크 분산** | 두 채널로 청중 확보 |
| **실행 가능** | 주 11-16시간으로 가능 |
| **차별화** | 기존 경쟁자와 다른 포지션 |
| **수익 경로** | 스폰서십 → 강의 → 컨설팅 |

| 기간 | 목표 | 액션 |
